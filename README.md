# 🏫 PHÒNG HỌC TIN HỌC ẢO 360° (WebXR)
### Bài 4: Làm việc với máy tính – Hướng dẫn bật và tắt máy tính đúng cách trong Windows 11

Website học tập thực tế ảo tương tác 360° dành cho học sinh tiểu học môn Tin học (Bộ sách *Kết nối tri thức với cuộc sống*).

---

## 🌟 Điểm nổi bật sau khi kiểm thử & tối ưu hóa
1. **Quy trình chuẩn xác, an toàn:**
   - **Hoạt động 1 (Bật máy tính):** Bước 1: Nhấn nút nguồn trên thân máy (CPU) ➔ Bước 2: Nhấn nút nguồn màn hình.
   - **Hoạt động 2 (Tắt máy tính trong Windows 11):** Đóng các chương trình đang mở (*Trình duyệt Web, RapidTyping*) ➔ Nhấn **Start** ➔ Chọn **Power (⏻)** ➔ Chọn **Shut down** ➔ Đợi đèn thân máy tắt hẳn rồi tắt màn hình.
2. **Giao diện Windows 11 hiện đại:** Thanh Taskbar căn giữa, hiệu ứng kính mờ, Start Menu trực quan.
3. **Thao tác mượt mà 100%:** Mở rộng vùng cảm ứng chuột (Hitbox 3D) quanh nút nguồn và tự động xoay camera chính diện máy tính khi chuyển bước.
